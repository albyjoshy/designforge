# Desktop design workflow
1. Inventory workflows requiring multitasking, data density and keyboard navigation.
2. Define navigation rail/sidebar, master-detail layout, tables, search and filtering.
3. Test resizing at 1024, 1280 and 1440 logical px and narrow windows.
4. Define focus states, pointer hover, tooltips, keyboard shortcuts and scrollbars.
5. For Flutter Windows, confirm plugin/platform support before proposing integrations.
6. Verify existing features and route parity after redesign.
