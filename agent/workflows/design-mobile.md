# Mobile design workflow
1. Choose primary actions and thumb-friendly navigation for each role.
2. Plan 360, 390 and 430 logical-pixel widths as examples, not universal targets.
3. Include system insets, keyboard behavior, dynamic text and accessibility labels.
4. Define loading, empty, offline, error and permission-denied states.
5. Implement token-based Flutter widgets; keep state management and API calls unchanged.
6. Validate Android and iOS behavior, including back navigation and text scaling.
