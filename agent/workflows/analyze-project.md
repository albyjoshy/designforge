# Analyze project
1. Identify repository framework, dependencies, navigation and screen inventory.
2. Inspect theme and reusable widgets, existing screenshots, localization and accessibility.
3. Document user personas, role permissions, key tasks and sensitive business rules.
4. Score navigation clarity, hierarchy, consistency, accessibility, responsiveness, state coverage and performance with supporting evidence.
5. Produce prioritized issues: severity, affected screen, evidence, recommendation, implementation risk.
6. Do not modify code in this phase. Ask for approval of the redesign scope.
